# 👋 Welcome to NetNavi OS — Start Here!

> You do not need to know how to code. Just follow these steps in order.

---

## 📦 Step 1 — Run the Installer

**Double-click this file in Finder:**
```
▶ INSTALL ME FIRST.command
```

A terminal window will appear. It will install everything your Navi needs automatically. **Do not close it** until it says "Installation complete!"

> ⚠️ If your Mac says the file "cannot be opened because it is from an unidentified developer":
> - Right-click the file → click **Open** → click **Open** again in the popup.
> - This only happens the first time.

---

## 🧠 Step 2 — Open Your Vault in Obsidian

After the installer finishes, open the **Obsidian** app.

> If Obsidian is not installed yet, download it free at: **https://obsidian.md**
> (The installer may have already installed it for you!)

When Obsidian opens:
1. Click **"Open folder as vault"**
2. Select the `NetNavi-OS-Mac` folder (the folder this file is in)
3. Click **Open**

Your Vault is now online.

---

## 🔑 Step 3 — Set Up Your Memory (Optional but Recommended)

To give your Navi long-term memory, double-click:
```
setup_keys.command
```

It will ask for your **Pinecone API key**. Get one free at **https://pinecone.io** — it takes 2 minutes to create an account.

You can skip this for now and do it later.

---

## 🤖 Step 4 — Connect Your AI

Install one of these AI assistants in this folder so it can read your `CLAUDE.md` and become your Navi:

| AI | Where to get it |
|---|---|
| **Antigravity** (recommended) | https://antigravity.google/ |
| **Claude** | https://claude.ai |
| **Gemini CLI** | Already installed by the installer! |

Once your AI is connected, open it and say:

> *"Read the CLAUDE.md file and tell me if you are operational."*

---

## 🧬 Step 5 — Name Your Navi and Begin

Your Navi is now alive. Tell it:
- The topics you care about
- What you want to use it for
- Your name (so it can address you as Operator)

The more notes and diary entries you create in this Vault, the more unique your Navi's **Ghost** becomes.

**Welcome to the network, Operator.** 🌐

---

## ❓ Something went wrong?

- Check the `README.md` for troubleshooting.
- Make sure you ran `▶ INSTALL ME FIRST.command` before opening Obsidian.
- If you skipped the Pinecone setup, the Navi will still work — it just won't have long-term memory yet.
